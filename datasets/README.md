# Datasets de referencia

Este directorio no almacena los datasets (por tamaño y licencias). La selección,
el uso recomendado y las consideraciones de privacidad están documentados en
[`../docs/ARQUITECTURA_SOC_LITE.md`](../docs/ARQUITECTURA_SOC_LITE.md), sección 6.

Resumen:

| Dataset | Uso principal |
|---|---|
| Microsoft GUIDE | Incidentes etiquetados y acciones de respuesta. |
| Splunk BOTS v3 | Simulación de investigaciones SOC. |
| OTRF Security Datasets | Telemetría Windows/Sysmon y TTP. |
| Splunk attack_data | Validación de detecciones y reglas. |
| CICIDS2017 / UNSW-NB15 | Detección de red y features de flujo. |
| LANL Cyber Dataset | Comportamiento anómalo y movimiento lateral. |
| AIT Log Data Set | Logs etiquetados de un entorno real. |
| Wazuh ruleset | Normalización y mapeo de severidad. |
| MITRE ATT&CK STIX | Enriquecimiento MITRE local. |
| NVD / EPSS / CISA KEV | Priorización de vulnerabilidades (roadmap). |
| AbuseIPDB / VirusTotal / GeoLite2 | Reputación y geolocalización (APIs). |

> No incluya datos personales o de organizaciones reales sin base legal, anonimización
> y aprobación del responsable de seguridad. Para la demo, SOC-Lite usa datos sintéticos.
